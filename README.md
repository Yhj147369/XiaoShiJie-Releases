# 《小世界》XiaoShiJie

> 一个 50m×50m 的低多边形剧情驱动单机垂直切片。  
> 核心循环：跑图 → 打怪 → 开箱 → 对话 → 升级

## 📥 下载

前往 [Releases](https://github.com/Yhj147369/XiaoShiJie-Releases/releases/latest) 下载最新版本。

- 解压压缩包
- 双击 `XiaoShiJie.exe` 运行
- **杀毒软件可能误报，请添加信任**（个人开发无数字签名）

## 🎮 操作

| 按键 | 功能 |
|:---|:---|
| W A S D | 移动 |
| 鼠标 | 转视角 |
| 空格 | 跳跃 |
| E | 交互（开箱、对话） |
| 鼠标左键 | 攻击 |
